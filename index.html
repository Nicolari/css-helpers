  • CSS Animations (keyframes.css)

    This file contains an example of animations using CSS keyframes. Implementation:
    1. insert a container such a "p" tag
    2. set the style to use the animation-name
    3. set a duration using animation-duration (i.e. 5s equal 5 seconds)
    4. use the animation-iteration-count style property to control how many times the animation plays


    DISCLAIMER: this is one example that could be used. Users could create many other animations using this as a template. It is up to the consumers to verify the expected output and test for usability.
